## Effect

[M13.effect.1] ATC confirms TSAT to the pilot in order to maintain the aircraft in the pre-departure sequence.
[M13.effect.2] Provided the aircraft was ready on time (ARDT), it is now up to ATC to assure that a regulated flight can respect its CTOT.

## Procedures

[M13.procedures.1] First step: To inform all relevant Airport CDM Partners of Actual Start up Request Time (ASRT) in the Airport CDM Platform.
[M13.procedures.2] Second step: to alert all relevant Airport CDM Partners when no start up has been re-quested inside the locally agreed TSAT tolerance window.
[M13.procedures.3] Inform of ASRT when it occurs.
[M13.procedures.4] If the start up request is not made by TSAT + tolerance, the AO/GH is informed that no start up has been requested, and should update TOBT.
[M13.procedures.5] Timestamp when the tolerance window has passed at TSAT.
